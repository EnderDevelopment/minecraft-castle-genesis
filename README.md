# Castle Genesis

Castle Genesis is a Minecraft plugin that adds a new block type to the game. When this block is placed, it generates a large castle with various structures such as shops, barracks, farms, temples, huts, and houses. Additionally, it includes special villages for warriors and cavalry. The plugin is designed to enhance the Minecraft world with detailed and functional castle environments.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Start or restart your Minecraft server.

## Use

1. Place a diamond block in the world.
2. Ensure you have an iron ingot in your inventory.
3. Place the diamond block to generate a castle at that location.
4. Use the `/generatecastle` command to generate a castle at your current location.
5. Use the `/castlesize <size>` command to set the size of the castle.
6. Use the `/ciao` command to greet yourself.
